## 手动 CLI 验收

使用 `--db data/smoke.db --session smoke`，分别执行独立进程：

1. `计算 12*(3+4)` → 84。
2. `再乘以 2` → 168，证明退出后仍能恢复工具上下文。
3. `记待办 周五复习` → 已写入。
4. 换 `--session other`，执行 `待办列表` → 空列表。
5. 回到 `smoke` 查询 → 原待办仍存在。

Windows 输出捕获在默认编码下出现乱码；加 `-X utf8` 后，同一数据库里的中文正常输出。

日期：2026-11-06；模型：`deepseek-v4.1-flash-1017`；接入：阿里云百炼兼容接口。8 项通过，总耗时 17.97 秒。结果摘要见 [LIVE_CHECK.json](LIVE_CHECK.json)。

使用 `scripts/live_check.py` 执行，判断依据包含实际工具结果和数据库状态。测试数据在临时目录中，进程退出后清除；凭证只用于进程环境，未写入结果摘要。

## 验证边界

- 本地 HTTP 自动测试与真实模型验收分开。默认单元测试不调用供应商接口；端到端验收使用上述真实模型。
- 脚本模型用于确定性测试；8 项真实验收是单模型的一次小规模检查，不能推断所有模型的任务成功率。
- 200 轮测试验证压缩发生、原文持久化与近期追问；没有证明任意早期事实都能正确召回。
- 本报告仅记录本地测试结果，未启用远程 CI。Python 3.11 为预期兼容版本，本地实际验证为 3.13。
- search 仍为 mock，真实模型接入通过不代表已经实现联网搜索。
- 自动测试与真实验收数据库位于临时目录；本地结果和手工 smoke 数据在忽略的 `data/`，不提交。
